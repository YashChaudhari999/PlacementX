# PROJECT: Enterprise Placement Management System – HR Collaborative Placement Drive Creation Module

You are an expert Senior Product Designer, Senior Full Stack Engineer, UX Researcher, Solution Architect, and Database Architect.

Design and implement a production-ready Enterprise Placement Management System for a college placement portal. The module should follow modern SaaS application standards similar to Workday, Greenhouse, Lever, SAP SuccessFactors, Darwinbox, and Zoho Recruit.

The objective is to eliminate manual work performed by the Placement Cell by allowing Company HRs to securely complete placement drive information through a unique invitation link generated by the Placement Cell.

The application must be scalable, secure, responsive, highly reusable, visually polished, and follow enterprise UI/UX standards.

UI REQUIREMENTS
────────────────────────────────────────

Before generating any page:

1. Design every page at Figma-quality.
2. Follow a professional enterprise design system.
3. Maintain visual consistency across all pages.
4. Use reusable components only.
5. Follow an 8px spacing grid.
6. Ensure WCAG accessibility compliance.
7. Support desktop, tablet, and mobile responsiveness.
8. Include loading states, skeleton loaders, empty states, success states, error states, and confirmation dialogs.
9. Use smooth animations (150–250ms) for transitions.
10. Use modern cards, tables, steppers, timelines, badges, chips, and drag-and-drop interactions.
11. Use a clean dashboard similar to Workday, Greenhouse, or SAP SuccessFactors.
12. Keep forms intuitive with contextual help and tooltips.
13. Optimize UX to minimize clicks and maximize productivity.
